# الماسية الأولى للتطوير العقاري — المقترح الثاني

مقترح تصميم (مفهوم "الماسة" الداكن) لموقع الماسية الأولى للتطوير العقاري. موقع ثابت بالعربي والإنجليزي.

- محتوى المشاريع وبيانات التواصل في `data/site.json`.
- نصوص الواجهة الثابتة في `assets/js/i18n.js`.
- لوحة التحكم تُطوَّر بعد اعتماد التصميم.
